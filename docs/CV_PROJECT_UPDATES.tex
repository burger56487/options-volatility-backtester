\entry
    {期权定价、波动率曲面与风险验证平台}
    {\href{https://github.com/burger56487/options-volatility-backtester}{GitHub}}
    {Python、C++、SciPy、蒙特卡洛}
    {2026}

\begin{itemize}
    \item 统一定价引擎：Black--Scholes、CRR 二叉树、有限差分、蒙特卡洛、
    Heston 与 Merton 跳跃扩散，全部通过退化/收敛测试（Heston 与 Merton 在
    极限下精确回到 Black--Scholes）。
    \item 接入真实 SPY 期权快照（2026-09-04）：6 个到期日共 1500 条报价，
    清洗后 872 条活跃报价中 734 条成功反解隐含波动率（138 条反解失败）；
    ATM 隐含波动率随期限由 9.3\% 升至 11.0\%，各到期 SVI 校准总方差
    RMSE 3.9e-5~1.7e-4。
    \item 将账户、执行引擎与交易前风控接入回测：真实 SPY 上 17 笔滚动跨式
    逐笔通过 PnL 桥对账（最大差异 3.5e-11），与 legacy 路径结果等价
    （总 PnL −8038.77 vs −8038.86）。
    \item 严格时间线（信号滞后一日）+ 训练/验证/测试隔离：5 组候选阈值
    （Bonferroni $\alpha=0.01$，跨边界交易排除在选择外）验证段选出 1.00，
    2025 测试段 2 笔交易、年化 Sharpe 1.42、PnL +2655.53（样本不足，
    如实标注）；配套 Kupiec/Christoffersen VaR 回测与样本量护栏。
    \item 数值验证（实测 2026-09-04）：CRR 步数 100→800 误差 0.017→0.002；
    Merton MC 20 万路径对级数解误差 0.001；VaR 回测 1194 天实际 87 例外 vs
    期望 60（Kupiec p=0.0007，Christoffersen p=0.78）。
\end{itemize}

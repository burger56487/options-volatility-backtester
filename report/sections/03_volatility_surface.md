# 3. 波动率曲面

## 3.1 数据管线

真实 SPY 期权快照（Cboe，2026-09-04，1500 条报价）经过统一 schema 校验、
报价清洗（买卖价、到期日、价差、无套利边界）、重复与孤立记录处理后：

- 活跃报价（OI>0 且 |log-moneyness|≤0.15）：872 条；
- 其中成功反解隐含波动率：**734 条**（138 条反解失败，与无套利违规一致）；
- ATM 隐含波动率随期限由约 9.3% 升至 11.0%（期限结构正常）。

## 3.1.1 五类质量分级（不删数据，逐行标记）

清洗流程对全部 1500 条报价逐行打质量标签（优先级从高到低：
invalid > out_of_range > low_liquidity > wide_spread > good），
不删除任何原始记录；完整带标签数据见
`outputs/real_option_chain/spy_quality_graded.csv`，
分级统计见 `outputs/real_option_chain/spy_grading_report.json`：

| 质量标签 | 数量 | 占比 |
|---|---:|---:|
| invalid（结构无效/交叉/过期） | 0 | 0.0% |
| out_of_range（\|log-moneyness\|>0.15） | 352 | 23.5% |
| low_liquidity（零成交且零持仓） | 218 | 14.5% |
| wide_spread（相对价差>0.5 且绝对价差超过 1 个 tick） | 0 | 0.0% |
| **good（进入分析子集）** | **930** | **62.0%** |

快照共 750 call / 750 put、6 个到期日。“good”与上文“活跃报价 872”
是两个口径：活跃子集按 OI>0 且 |log-moneyness|≤0.15 选取，
good 额外要求价差与流动性规则全部通过（宽价差规则带 1 tick 绝对下限，
避免把 0.01 档的价外期权标记为异常）；两者用途不同，
IV 反解与 SVI 校准仍基于 872 条活跃报价子集。

## 3.1.2 平价回归：隐含远期与利率/股息

对每个到期日做 put-call 平价回归 `C-P = D·(F-K)`（quality-good 配对、
价差噪声加权、中心化 + MAD 离群剔除），输出
`outputs/real_option_chain/spy_forward_estimates.{csv,json}`：

| 到期日 | 远期 F | 隐含利率 r | 隐含股息 q | 备注 |
|---|---:|---:|---:|---|
| 2026-09-08 | 773.17 | +22.0% | +22.0% | r/q 超出合理带 |
| 2026-09-09 | 773.23 | −6.9% | −7.5% | r/q 超出合理带 |
| 2026-09-10 | 773.30 | −6.9% | −8.0% | r/q 超出合理带 |
| 2026-09-11 | 773.52 | −11.2% | −13.5% | r/q 超出合理带 |
| 2026-09-14 | 773.59 | +1.9% | −0.1% | 通过 |
| 2026-09-15 | 773.67 | −16.0% | −18.2% | r/q 超出合理带 |

解读：**远期估计稳健**（R²≈0.9999，6/6 通过，且随期限单调抬升）；
但 SPY 本快照只剩 4–11 天的超短期限，`r=-ln(D)/T` 会把斜率噪声按
1/T（约 33–91 倍）放大，隐含利率/股息在相邻到期日之间符号翻转，
不能当作市场利率使用。因此后续 IV 反解采用市场隐含远期 F，
利率按公开市场利率固定（仓库默认 4%），股息采用 per-expiry ATM
平价估算（约 1.2%）；r/q 的回归结果作为数据质量诊断与较长期限
标的（如 3 个月以上）的分析预留。

## 3.2 SVI 校准

按到期日分组，用总方差 w(k)=σ²T 做带约束 SVI 拟合，实测 RMSE：

| 到期日 | 报价数 n | 总方差 RMSE |
|---|---|---|
| 2026-09-08 | 137 | 6.45e-5 |
| 2026-09-09 | 138 | 1.68e-4 |
| 2026-09-10 | 139 | 3.89e-5 |
| 2026-09-11 | 240 | 1.64e-4 |
| 2026-09-14 | 45 | 7.30e-5 |
| 2026-09-15 | 35 | 5.11e-5 |

所有到期日总方差 RMSE 均在 5e-4 以下（验证套件门槛）。
无套利检查（蝶式/日历）作为软规则标记违规行（原始 1500 条中 138 条），
活跃子集进入校准。

## 3.3 局限

- 单一快照不足以做跨日参数稳定性/随机波动率识别；
- SPY 期权为美式，当前 IV 反解用欧式边界近似，报告以远离深度实值、流动性
  较好的报价为主；美式/提前行权处理列为未来工作。

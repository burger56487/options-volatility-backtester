# 4. 回测框架

## 4.1 信息时点

第 t 日信号只用截至 t−1 日收盘可用的数据；成交发生在第 t 日的模拟可执行
报价上。所有波动率特征滞后一日并带 JSON sidecar 声明可用时间；审计模块拒绝
“观测截止晚于信号日”的特征表。回测 timeline 支持精确到事件级的时间语义。

## 4.2 样本外

训练/验证/测试三区段（2021–23 / 2024 / 2025），参数只在训练+验证中选择，
独立测试集只评估一次并被 `evaluation/test_evaluation_log.json` 锁定；
跨越 train/validation 边界的交易单独记录保留审计痕迹
（`boundary_crossing_trades.csv`）。4 组候选阈值 + Bonferroni 校正
（α=0.0125）。

## 4.3 执行与账户

订单/成交/现金账本/持仓/估值走组合级账户；执行引擎统一处理佣金、滑点、
市场冲击（作为归因字段而非重复扣费）、陈旧报价拒绝、限价单不可成交取消与
部分成交；融资、借券费、简化保证金、期权到期现金结算均入账。

## 4.4 PnL 桥对账

逐笔/逐日建立 TotalPnL ≈ Realised + Unrealised + Financing + BorrowFee +
Settlement − Fees 的对账恒等式。账户引擎滚动跨式：

- 17 笔交易，逐笔通过对账，最大绝对差异 **3.456e-11**；
- 总 PnL **−8038.7657**（-8.04%）；
- legacy close-to-close 路径（33 笔）总 PnL −8038.857，两者总量级一致，
  差异来自计费口径与设计差异（详见结果章）。

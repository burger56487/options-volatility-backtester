# 11. 结论与未来工作

## 结论

这个项目证明了一件事：期权研究的价值不在“赚不赚钱”，而在**结论是否
可信**。通过收敛/退化/恒等式/属性测试锁定定价正确性；通过严格时间线与
测试集锁定避免前视；通过 PnL 桥把账户引擎与旧路径对齐到 1e-11；用
Kupiec/Christoffersen 回测风险模型；把“亏钱的长跨式”解释为期权经济学的
正确预测，并用可复现的波动率状态过滤展示改善方向。过程中抓到的两个数值
bug（Heston CF 缺项、Euler 漂移偏差）反而成为“为什么要做验证”的最好论据。

## 未来工作

- 多标的（QQQ/IWM/GLD/TLT）与更长历史样本，提高统计功效；
- 真实历史期权链数据源与美式提前行权处理；
- Heston 等随机波动率模型的跨日参数校准与模型比较；
- 准蒙特卡洛（Sobol）与 Brownian bridge 方差削减；
- 做市 RL 与 DP 在更多参数区间的系统对照与样本外测试；
- Dashboard 原生读取 PostgreSQL、API 鉴权与部署加固；
- 可选的 pybind11 绑定层（当前 ctypes 已满足一致性与性能目标）。

# 10. 局限性

## 数据

- 样本量有限（滚动交易 6–33 笔、测试段 5 笔），统计功效低；
- 历史期权报价为**合成**数据（基于真实标的价格的透明模型）；真实期权链
  只有单日快照，未做策略回测数据源；
- 单标的（SPY），未做多标的验证；
- 历史链/跨日校准受公共免费数据可得性限制。

## 市场仿真

- 未模拟真实订单簿队列、撮合优先级与市场冲击反馈；
- 做市客户订单流为参数化模型（Poisson/Hawkes），不代表真实流量；
- 部分成交/延迟/停牌为规则简化。

## 建模

- 常参数简化：利率、股息为固定/简化曲线；美式期权用欧式近似
  （真实 SPY 期权为美式，需提前行权处理）；
- 保证金与借券成本是研究性近似，不代表交易所/券商规则；
- Heston 参数校准基于带标记的合成曲面（单快照不足以可靠识别随机波动率
  参数）。

## 工程

- API 无生产级高并发/认证/高可用；数据库默认 SQLite，PostgreSQL 为
  可选路径（已实现并经 CI 服务容器验证）；
- 看板读取 SQLite 输出库，Postgres 部署建议走 API 查询；
- 性能基准依赖硬件，CI 默认不跑 perf。

# 1. 引言

## 1.1 动机

本项目源于一个具体问题：期权策略研究中最难的不是“写公式”，而是让
“结果可信”。定价引擎有没有 bug？回测有没有前视？策略亏钱是方法问题还是
仿真问题？一个不能回答这些问题的回测平台，无论公式多漂亮都只能产出
“看起来很真”的数字。

因此我构建了一个端到端的期权研究平台，把每个环节都做成可验证的：
六种定价模型、真实 SPY 数据的波动率曲面、严格时间线的回测、统一执行引擎、
动态对冲、事件驱动做市仿真、C++ 加速与分层测试/CI。

## 1.2 研究问题

- 不同数值方法（解析、二叉树、有限差分、蒙特卡洛）如何收敛到同一个价格？
- 复杂模型（Heston、Merton）在极限参数下能否精确退化回 Black--Scholes？
- 在真实 SPY 标的价格 + 合成期权报价下，带交易成本的动态 Delta 对冲
  长跨式策略的收益结构是什么？
- 波动率状态过滤能否把系统性买入波动率的负收益改善为正值，且这种改善
  在样本外是否稳健？
- 连续时间事件驱动做市仿真中，固定价差、库存偏斜、Greeks 偏斜与
  Actor--Critic 策略的收益-风险对比如何？

## 1.3 贡献

- 统一的定价引擎与数值验证（收敛、退化、平价、无套利边界、属性测试）；
- 真实期权快照的报价清洗、隐含波动率反解与 SVI 校准（含无套利检查）；
- 严格信息时点的回测框架：信号滞后一日、训练/验证/测试隔离、测试集锁定、
  PnL 逐笔桥对账（最大差异 3.5e-11）；
- 组合级账户、执行引擎与交易前风控接入回测；
- 多合约 Greeks 感知做市与事件驱动 RL 研究栈；
- C++ 内核（批量定价/IV/MC/情景重估/组合 VaR）与一致性验证；
- 分层测试、模型验证报告与 CI（覆盖率门槛 80%）。

## 1.4 定位

这是**研究型仿真平台**，不是生产交易系统。历史策略回测基于真实 SPY
历史行情与透明的合成期权报价；做市与 RL 使用参数化订单流模型。报告对所有
简化假设与负结果做诚实披露。
